# The Daily Edit — News & Magazine

Group 3 replacement project: News & Magazine Website.

## Features
- Responsive magazine-style layout
- Story search and category filters
- Save/unsave story buttons
- Article preview modal
- Newsletter form with front-end confirmation
- Plain HTML, CSS and JavaScript

## Preview
Open `index.html` in a browser.

## Important
This is a fictional student magazine. Story titles and summaries are sample content, not current news. Search, filters, saved-state buttons, article preview and newsletter confirmation work in the browser. The newsletter does not store or send email addresses.
